# Boutique : réserver et payer une journée, offrir un bon cadeau

10 novembre 2026. Choix de Yoan : Stripe, la journée payée en entier (195 €), au départ les journées par date et les bons cadeaux. JB ouvre le compte Stripe au nom de l'association Promotion Sport Auto (email envoyé le 10 novembre).

## Ce que le client verra

1. **Sur une carte de date** (accueil, Académie) : « Réserver » ouvre une petite fenêtre : prénom et nom du pilote, âge pour le karting enfant, email, téléphone. Bouton « Payer 195 € ».
2. **La page de paiement Stripe** : carte, Apple Pay, Google Pay. Le site ne voit jamais la carte.
3. **Retour sur le site** : une page « Réservation confirmée » qui rappelle la date, le circuit et l'heure d'arrivée. Un email de confirmation part (fiche suivante, les emails).
4. **Bon cadeau** : sur l'Académie, « Offrir une journée » : formule, nom du bénéficiaire, message, paiement. Le bon arrive par email avec un code, valable un an ; le bénéficiaire saisit le code au moment de réserver sa date.

## Ce que JB verra

Dans le dashboard, un onglet **Réservations** : qui vient, à quelle date, payé ou non. La jauge des places de la date baisse seule. Un onglet **Bons cadeaux** : code, acheteur, bénéficiaire, utilisé ou non.

## Comment c'est construit

- **Deux fonctions Netlify** (le seul code côté serveur du site) :
  - `paiement` : reçoit la date ou la formule choisie, relit le prix dans la base (jamais celui envoyé par le navigateur), vérifie qu'il reste une place, crée la session Stripe et rend son adresse.
  - `stripe-retour` : appelée par Stripe quand le paiement est fait (webhook signé). Elle enregistre la réservation payée, met à jour les places, crée le bon cadeau et son code.
- **La base** : la table `inscriptions` existe déjà (prénom, nom, email, téléphone, statut). Ajouts : montant, référence Stripe, bon cadeau utilisé. Une table `bons_cadeaux`.
- **Les clés Stripe** restent dans les variables d'environnement de Netlify, jamais dans le code ni dans une conversation.
- **Mode test d'abord** : Stripe fournit des cartes d'essai. Tout est vérifié en mode test avant de passer au mode réel, sur ton accord.
